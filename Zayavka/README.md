# Zayavka — «Импорт заявок» (C# / .NET 10 / WinForms)

Перенос функциональности desktop-приложения «импорт заявок» (Lazarus / Free Pascal)
на C#. Акцент сделан на вкладке **«Паспорта оборудования»**: записи о работах
**сохраняются в файл паспорта Excel (`.xlsx`)**.

## Формат файла паспорта (Excel)

Файл: `<ПапкаПаспортов>/<НазваниеОборудования>/паспорт.xlsx`, лист **`паспорт`**.

| Столбец | Содержимое |
|---|---|
| A | `дата` (текст `dd.MM.yyyy`) |
| B | `Наработка, ч.` |
| C | `наименование работ` |
| D | `МТР, расходники` |
| E | `ед.изм.` |
| F | `кол-во` |
| G | `ссылка на доки` |
| **H** | **Начало работ** (`дд.ММ.гггг чч:мм`) |
| **I** | **Окончание работ** (`дд.ММ.гггг чч:мм`) |
| **J** | **№ заявки** |

* Создание паспорта пишет заголовок и стартовую запись
  «Создание паспорта оборудования» с текущей датой.
* Добавление работы вставляет строку **в хронологическом порядке по дате**
  (последующие строки сдвигаются вниз); дата для ручного ввода — текущая.
* Столбцы H/I/J дописываются в заголовок автоматически при первой записи
  (миграция старых паспортов — существующие данные не затрагиваются).
* CSV (`паспорт.csv`, разделитель `;`, Windows-1251) поддерживается как резервный
  формат; заголовок старых файлов также дополняется новыми столбцами.
* Поиск файла паспорта: `паспорт.xlsx` → `паспорт.xlsm` → `паспорт.csv` → любой `*.xlsx`/`*.xlsm` → любой `*.csv`.

## Связка «заявка → паспорт»

На вкладке «Импорт заявок» для выбранной заявки:

* **Копировать объём работ** — кладёт «Объём работ» заявки в буфер обмена;
* **Записать в паспорт** — определяет оборудование по заявке
  (`Префикс + Наименование + "-" + Номер`, напр. `1КЭН-3`), находит паспорт
  (точное, затем частичное совпадение имён) и добавляет запись в его Excel-файл.

Правила записи:

| Поле паспорта | Значение |
|---|---|
| `наименование работ` | «Объём работ» заявки (как есть) |
| `дата` | дата закрытия заявки (U), иначе дата окончания (N), иначе текущая |
| `Начало работ` | L (дата начала) + M (время начала) |
| `Окончание работ` | U/V (факт. окончание) или N/O (план), что есть |
| `№ заявки` | A (номер заявки) |

Строка вставляется **в хронологическом порядке** по дате записи. Если паспорт
не найден однозначно — открывается диалог выбора паспорта; при отсутствии
паспортов выдаётся подсказка указать папку на вкладке «Паспорта оборудования».
Перед сохранением создаётся резервная копия файла паспорта.

## Конфигурация

* `passport_config.ini` — папка паспортов (первая непустая строка; по умолчанию
  `<папка exe>/Паспорта оборудования`), задаётся кнопкой «Указать папку».
* `import_requests_config.ini` — путь к файлу журнала заявок, задаётся кнопкой
  «Выбрать файл» на вкладке «Импорт заявок».

## Вкладка «Импорт заявок»

Перенос логики `ImportRequestsTab.pas`. Первый лист журнала Excel; строка 1 — заголовок.

| Столбец (Excel) | Поле |
|---|---|
| A | Номер заявки |
| B | Дата подачи |
| D | Цех |
| E | Префикс |
| F | Сокращённое диспетчерское наименование |
| G | Номер оборудования |
| K | Объём работ |
| N | Дата окончания |
| W | Разрешение начальника цеха |
| X | Комментарий к разрешению |
| Y / Z | Дата / Время ввода в резерв |

* **Импорт** — открытой считается заявка, у которой пусты столбцы W и X.
* **Фильтр по цеху** — выпадающий список («Все цеха» + найденные цеха).
* **Закрыть заявку** — заполняет U (фактическая дата), V (фактическое время) и
  W = «Разрешено»; заявка перестаёт быть открытой.
* **Продлить заявку** — спрашивает новую дату окончания, добавляет в конец журнала
  новую заявку (номер = последний + 1, объём с пометкой «(Продление заявки №N)»),
  а в исходной строке пишет комментарий X «Заявка продлена. См. заявку №M».
* Перед записью создаётся резервная копия `<имя>_backup_ГГГГММДД_ЧЧММСС.xlsx`.

> ⚠️ Отличие от оригинала: исходный проект писал в журнал через COM-автоматизацию
> живого Excel (сохраняя оформление файла). Здесь используется ClosedXML — Excel
> на машине не нужен, но при сохранении файл перезаписывается движком ClosedXML.
> Для записи файл журнала должен быть закрыт в Excel.

## Сборка и тесты (любая ОС)

```bash
dotnet build Zayavka.slnx
dotnet test  Zayavka.slnx
```

Благодаря `EnableWindowsTargeting=true` решение компилируется и на Linux/CI.

## Запуск (Windows)

```bash
dotnet run --project src/Zayavka.WinForms
```

Публикация одним файлом без установки рантайма — **строго в канонический путь**
`publish/win-x64-selfcontained` (см. `.clinerules` / `AGENTS.md`):

```bash
cd Zayavka
dotnet publish src/Zayavka.WinForms -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true \
  -o publish/win-x64-selfcontained
```

или просто `./publish.sh` (Linux/Codespace) / `publish.cmd` (Windows).

Готовый файл: `publish/win-x64-selfcontained/Zayavka.WinForms.exe`.

## Особенности и ограничения

* Файлы паспортов и журнала должны быть закрыты в Excel во время записи
  (как и в исходном проекте).
* Запись выполняется «через временный файл» (`SafeFileWriter`), что исключает
  поведение, расцениваемое антивирусом/файловым сервером как ransomware.
